# create-lve

THE ULTRA-FAST FRONTEND STACK

```bash
pnpm create-lve
```

## Options

| Template | Description              |
| -------- | ------------------------ |
| React 19 | TanStack Router + Vite 8 |
| Vue 3    | Reka UI + Pinia          |

All templates ship with **Tailwind CSS v4** out of the box.

## Quick Start

```bash
# Interactive mode
pnpm create-lve

# Default (React 19 + TanStack Router + Tailwind)
pnpm create-lve my-app

# Skip all prompts
pnpm create-lve --default my-app
```

## What's Inside

- React 19 / Vue 3
- Tailwind CSS v4
- TypeScript
- Vite 8
- React Compiler (via `babel-plugin-react-compiler`)
- oxfmt + oxlint
- pnpm
